시작 가이드

🚀 교과교사가 사본 복사 후 가장 먼저 해야 할 일 4단계

학기 초 3분이면 우리 교과 전용 AI 자동 작성 환경이 완벽하게 준비됩니다.

1️⃣ 시트 사본 만들기

웹앱의 [관계형 시트]에서 [교과담임용 시트 사본 만들기]를 클릭하여 선생님 개인 구글 드라이브로 복사합니다.

2️⃣ 무료 Gemini API 키 등록

Google AI Studio에서 무료 API 키를 10초 만에 발급받은 뒤, 시트 상단 메뉴 🏆 생기부 올인원 > 🔑 Gemini API 키 설정에 등록합니다.

3️⃣ '_스킬지침' 탭 확인

_스킬지침 탭의 B2 셀에 있는 교과세특 작성 지침(첫 문장 형식, 팩트 기반, 종결어미 등)을 확인하고 우리 과목에 맞게 수정합니다.

4️⃣ 학생 관찰데이터 입력

순백색(#FFFFFF) 셀에 학번, 성명 및 구글 폼 설문 결과(F2:I2)를 붙여넣고 =AI('_스킬지침'!$B$2, F2:I2)를 실행합니다!

💡 최초 1회 Apps Script 권한 허용 안내

시트 메뉴에서 API 키를 등록하거나 커스텀 함수를 처음 실행할 때 구글의 [권한 검토] > [고급] > [이동(안전하지 않음)] > [허용]을 1회만 클릭하시면 영구적으로 자유롭게 동작합니다.

시트 서식 표준

🎨 시트 입력 색상 구분 규칙 & 1번 탭 대시보드

사본으로 저장한 구글 시트에서 어떤 칸을 입력해야 하는지 색상으로 1초 만에 구분합니다.

✏️ 순백색(#FFFFFF) 셀 = 선생님 직접 입력 칸

  • 2_수강생명렬표: 학번, 성명, 희망진로/학과
  • 3_수업관찰_기록: 수업 중 관찰 메모, 수행평가 발표 주제, 질문 내용
  • 4_AI세특_작성: 구글폼 설문 복사 열 (F열 주제, G열 선정이유, H열 대화핵심, I열 참고링크)
  • _스킬지침: 우리 학교/과목 맞춤 프롬프트 지침 텍스트
👉 이 칸들만 채우시면 모든 계산과 작성이 자동으로 이루어집니다!

🔒 유색(회색·하늘색·연두색) 셀 = 자동 계산 칸 (수정 금지)

  • 자동 채번 및 학번 연동: =IF('2_학생명렬표'!A5="","",...)
  • AI 생성 세특 초안: =AI('_스킬지침'!$B$2, F2:I2)

  • 1_종합대시보드: 누락 항목 통계, 진행률, 상태 배지(🟢, 🟡, 🚨)
👉 회색 칸의 수식을 실수로 지우면 연결이 끊기므로 건드리지 마세요.

AI 함수 가이드

🤖 =AI() 단일 함수로 교과세특 1초 완성하기

복잡한 프롬프트는 _스킬지침 탭의 특정 셀에 보관하고, 본문에서는 셀 주소만 참조하여 깔끔하게 작성합니다.

⭐️ 표준 권장 수식: 프롬프트 셀 참조 + 설문 범위 지정

=AI('_스킬지침'!$B$2, F2:I2)

• 첫 번째 인수 '_스킬지침'!$B$2: 고등학교 교사 역할, 3단 논법, 1500B 이내, 개조식 종결 등 기재요령 프롬프트
• 두 번째 인수 F2:I2: 학생이 제출한 주제(F), 선정이유(G), 제미나이 대화핵심(H), 참고링크(I) 범위 자동 병합

단일 관찰 메모 셀 참조 방식

=AI('_스킬지침'!$B$2, D2)

D2 셀에 적힌 선생님의 수업 관찰 메모 1줄을 바탕으로 교육부 기재요령을 완벽 준수한 3단 구조 세특 초안을 생성합니다.

전교생 원클릭 전체 완성 꿀팁

첫 번째 학생(E2)에 수식을 입력한 후, 셀 우측 하단 모서리(채우기 핸들)를 더블클릭하면 30명 전체 행으로 자동 복사되어 1초 만에 완비됩니다!

FAQ & 운영 팁

💡 자주 묻는 질문(FAQ) 및 선생님 꿀팁

안전하고 편리한 생기부 작성을 위한 핵심 체크포인트

Q1. 학생 개인정보가 구글 서버로 유출되나요?

A. 아닙니다. 이 시트는 선생님의 개인 구글 드라이브에 저장되며, =AI() 호출 시에도 학생 이름은 전달하지 않고 활동 내용(F2:I2)만 전송하므로 개인정보가 완벽히 보호됩니다.

Q2. Gemini API 키는 무료인가요?

A. 네, 구글 계정당 분당 15회 호출까지 100% 무료(Free Tier)로 제공되며, 고교 학급 30명 세특 작성에는 충분한 용량입니다.

Q3. 다른 과목으로 프롬프트를 바꾸려면?

A. _스킬지침 탭의 B2 셀 문구를 복사하여 B3, B4 등에 과목별(수학, 영어, 과학 등)로 지침을 적어두고 =AI('_스킬지침'!$B$3, F2:I2)처럼 셀 주소만 바꾸시면 됩니다.

Q4. 나이스에 입력할 때 주의할 점은?

A. AI가 생성한 초안은 선생님이 학생의 실제 활동 여부를 최종 확인하고 검토한 후, 완성된 문구를 나이스 [교과세특] 란에 복사하여 붙여넣으시면 됩니다.
