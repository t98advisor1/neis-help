[화면 01] 종합 대시보드

종합 대시보드 및 시스템 메인 관제 허브

학번(ID)을 기준으로 8개 탭의 진행 현황과 항목별 결손(미완성) 상태를 실시간 진단합니다.

실제 구동 화면: 메인 대시보드 (capture_1_dashboard.png)

1. 화면 구성 요소

  • 상단 원페이지 단계 탭: [관계형시트], [점검기], [2027대입], [초안생성], [교무수첩], [AI프롬프트], [설명서]로 즉시 전환
  • 핵심 지표 통계 카드: 등록 학생 수, 명렬표 완성률, 세특 완료율, 상담 미실시 현황을 4개 카드로 자동 집계
  • 학생별 점검표 테이블: 학번, 성명, 희망진로 및 각 항목별 상태 배지([완비], [보완 필요], [미작성]) 표시

2. 교사 조작 절차

  1. 학기 초 또는 마감 기간 중 화면 상단의 [학생별 점검표]를 확인합니다.
  2. 상태가 [미작성] 또는 [보완 필요]로 표기된 학생의 우측 [바로가기] 버튼을 클릭합니다.
  3. 해당 학생의 세특 초안 생성 또는 상담 화면으로 1초 만에 이동하여 즉시 보완합니다.

3. 시스템 핵심 기능

학번(5자리) 하나로 모든 기록이 상호 연결되어 있어 중복 입력 없이 데이터 누락을 원천 차단합니다.

[화면 02] 시트 사본 & 색상 규칙

관계형 구글 시트 사본 생성 및 셀 입력 색상 규칙

학급담임용과 교과담임용 2분할 사본을 제공하며, 흰색 셀에만 데이터를 입력합니다.

실제 구동 화면: 관계형 시트 탭 (capture_2_sheet_cards.png)

1. 화면 구성 요소

  • 카드 1 (학급담임용 시트): 명렬표, 창체·행특, 대입상담, 개인별 종합누적, 교과세특 연동 탭 포함
  • 카드 2 (교과담임용 시트): 수강생명렬표, 수업관찰, AI세특작성, 담임시트 내보내기 탭 포함
  • 색상 구분 안내 배너: 순백색(직접 입력) vs 유색(수식/자동 계산) 표준 안내 상단 고정

2. 교사 조작 절차

  1. 교과담당 교사는 카드 2의 [교과담임용 시트 사본 만들기] 초록색 버튼을 클릭합니다.
  2. 구글 드라이브 화면에서 [사본 만들기]를 승인하여 본인 구글 계정에 저장합니다.
  3. 시트가 열리면 오직 순백색(#FFFFFF) 셀에만 학생 명렬 및 설문 응답을 입력합니다.

3. 수정 금지 셀 주의사항

연회색(#F8FAFC) 또는 연하늘색(#EFF6FF) 배경 셀은 자동 계산 수식 및 연동 셀이므로 내용을 지우거나 임의 수정하지 마십시오.

[화면 03] AI 세특 워크벤치

교과세특 =AI() 단일 함수 작성 및 지침 셀 참조

프롬프트를 지침 탭 B2 셀에 보관하고 본문에서는 셀 주소만 참조하여 초안을 생성합니다.

실제 구동 화면: AI 세특 작성기 (capture_3_ai_workbench.png)

1. 표준 권장 함수 공식

=AI('_스킬지침'!$B$2, F2:I2)
  • '_스킬지침'!$B$2: 교과세특 9대 규칙 프롬프트가 보관된 셀 (절대참조)
  • F2:I2: 학생이 작성한 [주제], [동기], [AI 대화핵심], [참고링크] 범위 일괄 전달

2. 교사 조작 절차

  1. 시트의 4_AI세특_작성 탭 F~I열에 학생 구글 폼 설문 응답 데이터를 붙여넣습니다.
  2. 첫 번째 학생인 E2 셀에 위 =AI() 수식을 입력하고 Enter를 누릅니다.
  3. 초안이 생성되면 E2 셀 우측 하단 채우기 핸들 점을 마우스 더블클릭합니다.
  4. 전체 학생(30명)의 행으로 수식이 자동 복사되어 전원 초안이 일괄 완성됩니다.

3. 단일 관찰 메모 셀 참조 공식

=AI('_스킬지침'!$B$2, D2)

수업 중 D2 셀에 남긴 한 줄 관찰 메모만으로도 나이스 1,500 Byte 3단 구조 초안 생성이 가능합니다.

[화면 04] AI 프롬프트 패널

영역별 AI 프롬프트 및 스킬 지침 6대 영역

교과세특, 행특, 자율, 동아리, 진로 및 6번 학생 보고서 OCR 판독 카드를 제공합니다.

실제 구동 화면: 프롬프트 패널 (capture_4_prompts.png)

1. 화면 구성 요소

  • 1~5번 카드: 교과세특(1,500B), 행동특성(1,500B), 자율활동(1,500B), 동아리활동(1,500B), 진로활동(2,100B) 표준 기재 지침
  • 6번 카드 (초록색 강조): [학생 보고서·설문지 OCR 판독] 전용 카드
  • 원클릭 실행 버튼: [지침 복사], [SKILL.md 다운로드], [판독기 열기]

  1. 상단 네비게이션에서 [AI 프롬프트·스킬] 탭을 클릭합니다.
  2. 원하는 작성 영역 카드의 [지침 복사] 버튼을 누르면 클립보드에 복사됩니다.
  3. 구글 시트의 _스킬지침 탭 해당 셀에 붙여넣어 우리 학교/과목 맞춤형으로 편집합니다.

3. 파일 다운로드 지원

[SKILL.md] 버튼을 클릭하면 표준 마크다운 형식 파일로 즉시 다운로드되어 오프라인 보관이 가능합니다.

[화면 05] OCR 판독 & 보안

학생 보고서·설문지 OCR 판독기 및 교육용 계정 보안

종이 보고서 사진을 일괄 판독하여 구글 시트 복사용 마크다운 표로 추출합니다.

실제 구동 화면: OCR 판독 모달 팝업 (capture_5_ocr_modal.png)

1. 학생 데이터 보호 필수 보안 권장

학생들의 설문지 및 탐구보고서 사진에는 개인정보와 학습 기록이 담겨 있습니다. 본 작업 시 AI 모델 학습을 하지 않는다(No Model Training)고 계약된 구글 교육용 계정(@sch.hs.kr, @goedu.kr 등) 사용을 적극 권장합니다.

2. OCR 판독 및 9대 규칙 핵심

  • 이미지 판독: 학생 손글씨·비문 자동 교정, 과학·수학 기호 원형 복원, 4대 항목 분별
  • 첫 문장 고정: "과제연구 시 '[주제]'를 주제로 선택하였으며 AI를 활용해 학술자료를 조사하고 분석함."
  • 9대 규칙: 팩트 기반, 주어 생략, 작은따옴표 감싸기, 내면 감정 배제, 100~250자 준수

3. 교사 조작 절차

  1. [판독기 열기]를 눌러 [표준 프롬프트 복사] 버튼을 클릭합니다.
  2. Gemini(gemini.google.com)의 [Gems 매니저] > [+ 새 Gem]의 지침란에 붙여넣습니다.
  3. 학생 보고서 사진을 드래그하여 올리면 마크다운 표가 출력되며, 시트에 바로 붙여넣습니다.
[화면 06] 나이스 제약 점검

교육부 나이스 4대 기재요령 제약 실시간 사전 점검기

나이스 전송 전 전산 바이트 초과, 금지어, 불필요한 주어, 종결어미를 실시간 검증합니다.

실제 구동 화면: 기재요령 점검기 (capture_6_constraint.png)

1. 4대 실시간 점검 영역

  • 1,500 Byte 계산: 한글 3B, 영문/숫자/공백 1B, 줄바꿈 2B의 교육부 공식 완벽 반영
  • 금지어 적발: 공인어학시험, 교외 수상실적, 사교육 기관명, 부모 직업 실시간 하이라이트
  • 주어 생략 검증: '이 학생은', '본인은' 등 불필요한 주어 즉시 적발
  • 개조식 종결어미: 문장 끝이 '-함', '-임', '-음'으로 끝나는지 검증

2. 교사 조작 절차

  1. 상단 네비게이션에서 [점검기] 탭을 클릭합니다.
  2. 작성된 문구를 본문 입력란에 붙여넣습니다.
  3. 우측 패널에 즉시 나타나는 위반 항목 확인 후 [원클릭 교정] 버튼을 누릅니다.
  4. 초과 바이트가 해소되고 금지어가 제거된 완성 문구를 나이스로 복사합니다.

[화면 09] 관리자 승인 체계

교사 이용 승인 및 관리자 시트 운영 체계

관리자는 체크박스 원클릭으로 교사 계정에 이용권을 부여하고 만료일을 자동 관리합니다.

실제 구동 화면: 관리자 승인 매뉴얼 (capture_9_admin.png)

1. 3단계 승인 파이프라인

  • 1단계 교사 신청: 교사가 구글 계정으로 로그인 또는 승인 신청 시 시트 행 자동 생성
  • 2단계 관리자 체크: 관리자 시트 2_교사승인명단 A열 체크박스 클릭 즉시 승인
  • 3단계 자동 계산: 승인일 기준 만료예정일 자동 계산 및 관리자 대시보드 실시간 집계

2. 교사승인명단 열(Column) 구성

  • A열 [승인여부]: TRUE/FALSE 체크박스
  • B~E열 [신청정보]: 신청일시, 성함, 소속학교, 이메일 자동 기록
  • F열 [자동승인 플래그]: 교육청/학교 공식 도메인 자동 승인 판별
  • H열 [이용권 연장]: 추가 연장 시 연장 횟수(1, 2...) 입력으로 만료일 갱신

3. 분리 운영의 원칙

일반 교사용 화면에는 관리자 시트가 노출되지 않으며, 전용 페이지(admin.html)에서 독립적으로 운영됩니다.

STEP 01: 교과담임용 시트 사본 만들기

웹앱의 [관계형 시트] 패널에서 [교과담임용 시트 사본 만들기]를 클릭하여 본인의 구글 드라이브로 복사합니다.

STEP 02: 무료 Gemini API 키 등록

Google AI Studio(aistudio.google.com)에서 무료 API 키를 발급받은 뒤, 시트 상단 메뉴 [생기부 올인원] > [Gemini API 키 설정]에 등록합니다.

STEP 03: '_스킬지침' 탭 프롬프트 확인

_스킬지침 탭 B2 셀의 기재요령 프롬프트 문구를 확인하고 우리 과목(수학, 국어, 영어 등)에 맞게 조정합니다.

STEP 04: 설문 응답 입력 및 =AI() 실행

순백색 셀(F~I열)에 학생 설문 결과를 붙여넣고 E2 셀에 =AI('_스킬지침'!$B$2, F2:I2)를 실행합니다.

최초 1회 Apps Script 보안 권한 허용 절차

시트 메뉴에서 API 키를 처음 등록하거나 커스텀 함수를 실행할 때 구글의 보안 확인 창이 표시됩니다. 이는 매크로 정상 구동을 위한 표준 절차입니다:

  1. [권한 검토] 버튼 클릭
  2. 본인의 구글 계정 선택
  3. 좌측 하단 [고급 (Advanced)] 링크 클릭
  4. [안전하지 않은 페이지로 이동] 클릭
  5. 우측 하단 [허용 (Allow)] 클릭

※ 최초 1회만 허용하면 이후에는 추가 권한 요청 없이 영구적으로 동작합니다.

[안내] 자주 묻는 질문 FAQ

선생님 필수 질문 답변 및 시스템 오류 대처 요령

안전하고 원활한 생기부 작성을 위한 핵심 체크포인트

Q1. 학생 개인정보가 구글 서버로 유출되지 않나요?

답변: 유출되지 않습니다. 본 시트는 선생님의 개인 구글 드라이브 계정 안에서만 동작하며, =AI() 함수 호출 시에도 학생 이름은 전달하지 않고 순수 학술 활동 내용(F2:I2)만 전송하므로 개인정보 보호 법령을 준수합니다.

Q2. Gemini API 키는 비용이 청구되나요?

답변: 분당 15회 호출까지 완전 무료(Free Tier)로 제공됩니다. 고등학교 1개 학급 30명 세특을 작성하기에 충분한 용량입니다.

Q3. 다른 교과목 프롬프트로 변경하려면 어떻게 하나요?

답변: _스킬지침 탭의 B2 셀을 B3, B4 등에 복사하여 과목별 지침을 적어두고, =AI('_스킬지침'!$B$3, F2:I2)처럼 셀 주소만 변경하시면 됩니다.

Q4. 수식을 실수로 지웠을 때는 어떻게 하나요?

답변: 즉시 Ctrl + Z (실행 취소)를 누르거나, 윗 행의 수식 셀을 아래로 끌어내려 복사하시면 복구됩니다.

Q5. 생성된 세특 문구를 나이스에 바로 등록해도 되나요?

답변: 생기부는 교사의 직접 관찰 기록이 법적 근거입니다. AI가 작성한 초안을 선생님께서 반드시 최종 검토(Review)하신 후 나이스에 등록하셔야 합니다.
