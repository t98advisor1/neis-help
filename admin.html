[원인 및 연동 원리]
구글 시트는 외부 사이트에서 임의로 데이터를 쓸 수 없도록 구글 보안 정책으로 차단되어 있습니다.
따라서 구글 시트 내부의 [Apps Script]를 '웹 앱으로 배포(액세스 권한: 모든 사용자)'하여 고유한 수신 주소(URL)를 생성한 뒤, 웹앱 설정 또는 Vercel 환경변수(ADMIN_GAS_URL)에 등록해야 구글 로그인하는 즉시 시트로 행이 자동 추가됩니다.

[설정 순서] 웹 앱(Web App) 1분 배포 및 연결 절차

STEP 1. Apps Script 열기

관리자 승인 시트 상단 메뉴에서 확장 프로그램 > Apps Script를 클릭합니다.

STEP 2. 통합 스크립트 코드 붙여넣기

기존 코드를 모두 지우고 프로젝트의 google_apps_script_dual_relational.js 코드를 전체 붙여넣은 뒤 Ctrl+S(저장)를 누릅니다.

STEP 3. 웹 앱으로 배포하기 (가장 중요)

우측 상단 파란색 [배포] 버튼 > [새 배포] 클릭 -> 유형: [웹 앱] 선택 -> 다음 권한으로 앱 실행: [나] -> 액세스 권한: [모든 사용자(Anyone)] 선택 -> [배포] 클릭 후 발급된 https://script.google.com/macros/s/.../exec 주소를 복사합니다.

STEP 4. Vercel 또는 웹앱에 등록

Vercel 대시보드의 Environment Variables에 ADMIN_GAS_URL을 추가하거나, 웹앱의 마스터 설정(비번 0909)에 붙여넣으시면 모든 기기에서 구글 로그인 시 실시간으로 기록됩니다.

[운영 절차] 일상 교사 승인 3단계 프로세스

[STEP 01] 교사 접속 및 자동 행 추가

선생님이 웹앱에서 Google 로그인을 하면, 관리자 시트 [2_교사승인명단]에 접속 시각, 성함, 소속 학교, 이메일이 실시간으로 1행 자동 생성됩니다.

[STEP 02] A열 체크박스 클릭 = 즉시 승인 (30일 부여)

관리자 선생님은 시트 A열의 체크박스 [V]를 클릭하기만 하면 됩니다. 클릭 즉시 해당 선생님 계정에 1개월(30일) 정식 이용권이 부여됩니다.

[STEP 03] 교사 즉시 입장 및 만료일 자동 계산

승인된 교사는 비밀번호 없이 사이트에 1초 만에 입장하며, 시트에서는 30일 후 만료일을 자동 계산하고 [1_승인대시보드]에 활성 교사 수가 자동 집계됩니다.
