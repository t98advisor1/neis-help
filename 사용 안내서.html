1. 열기

  1. 받은 zip을 풀고 폴더를 바탕화면 등에 둡니다.
  2. 폴더 안 생기부 초안 도우미.html을 크롬이나 엣지로 엽니다(더블클릭). 인터넷 연결이 필요합니다. 그림 안내는 참고 이미지 폴더에 있습니다.

2. 쓰는 순서 (✏️ 만들기 탭)

  1. 항목(교과세특·자율자치·동아리·진로·행동특성) → 기본 정보(학년·과목, 반·번호는 선택) → 관찰 메모(무엇을·어떻게·결과). 메모 아래 칸에서 교과세특 성취기준과 실제로 본 특성·변화·참여도를 골라 더할 수 있습니다(선택).
  2. 분량·역량·예시를 고릅니다(안 고르면 알아서).
  3. 결과 받기: 아래 둘 중 하나
    • 앱에서 바로 만들기 — Gemini API 키 필요(❓ 안내 → "Gemini API 키 받기", 무료)
    • 프롬프트 복사해서 쓰기 — 키 없이 ChatGPT·Gemini·Claude 채팅에 붙여 넣기
  4. 완성 문단 아래 점검 결과(글자 수·금지 표현)를 보고 고친 뒤 복사해 초안으로 다듬어 쓰기(나이스에는 선생님이 최종 확인한 문장을 입력). 저장함에 넣기를 누르면 📋 저장함에 모입니다.

3. 꼭 지킬 것

  • 메모에 학생 이름·학번·학교명·연락처를 적지 마세요. 무료 Gemini는 보낸 내용이 구글 서비스 개선에 쓰이고 검토하는 사람이 읽을 수도 있습니다.
  • 기재요령은 AI가 만든 글을 그대로 입력하는 것을 금지합니다(19쪽). 초안은 반드시 선생님이 확인·수정한 뒤 입력하세요.
  • 만들기 4번 '메모가 짧을 때'에서 약간의 과장 허용을 고르면 메모에 없는 내용이 들어갑니다. 한 문장씩 메모와 대조해 사실이 아닌 부분을 고치세요. 결과 아래에 AI가 덧붙였다고 밝힌 내용과 늘리기로 더한 문장이 목록으로 나오니 그것부터 보세요(목록에 없는 덧붙임도 있을 수 있어요).

4. 저장과 옮기기

  • 저장함은 이 컴퓨터의 브라우저에만 남습니다. 가끔 📋 저장함 → 백업 파일 저장을 해 두세요. 다른 컴퓨터에서는 백업 파일 불러오기로 옮깁니다(API 키는 다시 입력).
  • 학급 전체 문단은 저장함 → 엑셀 파일 받기로 한 번에 받을 수 있습니다.
  • 교무실 공용 PC라면 다 쓴 뒤 ❓ 안내 → 이 기기의 앱 데이터 모두 지우기. 재부팅 때 기록을 지우는 PC는 저장함이 사라질 수 있으니 백업을 자주 하세요.
  • 이 앱을 쓰는 크롬에서는 메일·메신저로 받은 출처 모를 HTML 파일을 더블클릭해 열지 마세요. 파일로 연 HTML은 저장 공간을 함께 써서 이 앱의 API 키·저장함을 읽을 수 있습니다.

5. API 키 없이 쓰기 (구독·무료 채팅)

  • 구독(Claude Pro·Google AI Pro·ChatGPT Plus 등)은 API와 별개라 "앱에서 바로 만들기" 한도(하루 15명 안팎)는 늘지 않습니다.
  • 무료 사용량을 다 썼거나 평소 쓰는 채팅(Gemini·ChatGPT·Claude)에서 받고 싶으면 프롬프트 복사해서 쓰기를 씁니다. 구독이 있으면 지침을 채팅에 한 번 저장해 두고 학생마다 메모만 보내세요 — ChatGPT는 지침만 복사(프로젝트 지침), Claude는 스킬 파일 받기(스킬에 올리기), Gemini는 둘 중 하나. 받은 문단은 만들기 5번 채팅에서 받은 문단 점검하기로 점검·저장합니다.
  • 개인 구독 채팅은 설정에서 "모델 개선에 사용"을 끄고, 학생 이름·학번은 빼고 보내세요.
